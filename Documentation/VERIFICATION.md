# Verification — how we know "who said what" is right

The #1 requirement: the app is 100% testable and loggable. The diarizer's neural core is a
Core AI export of NVIDIA's Sortformer whose fidelity is never assumed — everything below
makes it checkable. (The model shipping here is a local re-export; provenance + regeneration:
`SORTFORMER-STATUS.md`.)

## Automated gates (run with the test suite)

1. **Mel-frontend gate** — golden mel spectrograms for committed test clips, generated by
   an independent Python reference (librosa/NumPy — *not* NeMo, so the check is
   independent), compared on the **linear** mel stage. (Gating the log-mel on cosine is a
   known trap: the log expands the silence floor and dominates the metric while speech
   bins match exactly.)
2. **AOSC unit tests** — the speaker-cache compression math on synthetic tensors,
   including the padded-count top-k indexing trap documented in the conversion's handoff
   (an index shift that is invisible on short clips).
3. **Synthetic ground-truth attribution test** — `scripts/make-verification-audio.sh`
   builds two-voice dialogues (`say`, acoustically distinct voices) with machine-known
   turn boundaries (`TestResources/*.json`). The test diarizes the WAV, optimally maps
   anonymous slots to ground-truth speakers, and asserts frame-level speaker-attribution
   accuracy ≥ 85%. The long variant (>60s) forces cache compression to fire — a short clip
   never exercises it. **As-built:** the always-on gate runs through SpeakerKit: short
   **92.6%** / long **93.1%** on this Mac. The same gate through the real Sortformer model
   passes under the env flag (see below), cross-checked against SpeakerKit in the same test.
4. **Cross-check** — SpeakerKit (Argmax, an independent diarizer) over the same clips;
   large disagreement fails loudly and is inspectable in-app (env-gated with the model gate).
5. **Concurrent-load bench** — `CONCURRENT_BENCH=1 swift test --filter ConcurrentLoadBench`
   measures ASR-alone, diarize-alone, and both-at-once on the long clip with thermal states
   (`[BENCH]` lines). M4 as-measured: ASR RTF 0.046, Sortformer RTF 0.015; concurrent ASR
   ×1.01, diarizer ×1.43, thermal nominal throughout.

### The Sortformer model gates are env-flagged, not auto-probed

A bad/stale `.aimodel` fails with a **fatal, uncatchable `LLVM ERROR` process abort** — a load
can never be a fallible probe ("try, fall back on failure" is impossible). Tests that load the
model are therefore opted in by a human who knows the provisioned model loads:

```
SORTFORMER_MODEL_OK=1 swift test --filter Sortformer
```

Without the flag those tests skip and the suite stays green. The mel frontend and AOSC math
are verified independently of the model (gates 1–2, always on), and the full streaming loop +
AOSC compression run end-to-end against a fake graph (`SortformerLoopTests`) — everything
except the neural forward's *values* is covered without the model.

## The human loop (Fernando, daily)

1. Record a real meeting or room conversation.
2. The live transcript shows who-said-what with per-segment confidence; provisional
   labels are visually distinct from committed ones.
3. Open the Inspector: per-frame speaker-activity heatmap (the model's raw sigmoids),
   ASR confidence table, per-stage latencies, thermal/CPU under load.
4. **Click any segment to play its audio** — ear vs. label in one click.
5. Diarizer A/B: run the same session through SpeakerKit and compare timelines.

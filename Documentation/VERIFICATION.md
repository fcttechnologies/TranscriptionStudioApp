# Verification — how we know "who said what" is right

The #1 requirement: the app is 100% testable and loggable. The diarizer is a community
Core AI conversion whose fidelity was byte-gated against NeMo on only two clips and never
re-measured for DER — so nothing about it is trusted; everything below makes it checkable.

## Automated gates (run with the test suite)

1. **Mel-frontend gate** — golden mel spectrograms for committed test clips, generated by
   an independent Python reference (librosa/NumPy — *not* NeMo, so the check is
   independent), compared on the **linear** mel stage. (Gating the log-mel on cosine is a
   known trap: the log expands the silence floor and dominates the metric while speech
   bins match exactly.)
2. **AOSC unit tests** — the speaker-cache compression math on synthetic tensors,
   including the padded-count top-k indexing trap documented in the conversion's handoff
   (an index shift that is invisible on short clips).
3. **Synthetic ground-truth attribution test** — `scripts/make-verification-audio.sh`
   builds two-voice dialogues (`say`, acoustically distinct voices) with machine-known
   turn boundaries (`TestResources/*.json`). The test diarizes the WAV, optimally maps
   anonymous slots to ground-truth speakers, and asserts frame-level speaker-attribution
   accuracy over a threshold. The long variant (>60s) forces cache compression to fire —
   a short clip never exercises it.
4. **Cross-check** — SpeakerKit (Argmax, an independent diarizer) over the same clips;
   large disagreement fails loudly and is inspectable in-app.

## The human loop (Fernando, daily)

1. Record a real meeting or room conversation.
2. The live transcript shows who-said-what with per-segment confidence; provisional
   labels are visually distinct from committed ones.
3. Open the Inspector: per-frame speaker-activity heatmap (the model's raw sigmoids),
   ASR confidence table, per-stage latencies, thermal/CPU under load.
4. **Click any segment to play its audio** — ear vs. label in one click.
5. Diarizer A/B: run the same session through SpeakerKit and compare timelines.

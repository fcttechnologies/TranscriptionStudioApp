# AGENTS.md — Transcription Studio

Standing instructions for any agent working in this repo. Pointers only: read the file named, don't assume its contents.

- **Read first: [`README.md`](README.md)** (setup + the CLI), then [`Documentation/PROJECT_GUIDE.md`](Documentation/PROJECT_GUIDE.md) and, for the area you're changing, its own doc beside it; **the trap reference is `~/Jarvis/projects/transcription-studio/learnings.md`** (share-extension memory caps and plist mechanics, the companion flow, target topology) — learnings live in the workspace for every project, this one included, so there is exactly one home to read and to write back to.
- **Setup facts that bite:** run `scripts/fetch-models.sh` first; the Sortformer neural core must be a **locally re-exported** `.aimodel` — the HF-published one doesn't load ([`Documentation/SORTFORMER-STATUS.md`](Documentation/SORTFORMER-STATUS.md) has the recipe). Without it the app falls back to SpeakerKit diarization.
- **Gate:** `scripts/gate.sh` — the host suite, both platforms built warning-free, and the artifact reads nothing else catches (the App Shortcuts provider actually registering, the two bundle ids, which appex is embedded where, the macOS entitlements). `SIM_NAME` points it at your own simulator. The real-model and bench suites are env-gated and off by default — `SORTFORMER_MODEL_OK=1 swift test --filter Sortformer`, `CONCURRENT_BENCH=1 swift test --filter ConcurrentLoadBench`, `LUXTTS_MODEL_OK=1 swift test --filter LuxTtsLive` (real cloned synthesis; needs a voice profile on disk) — run them when touching those paths. Verification audio: `scripts/make-verification-audio.sh`.
- **`transcribe-cli` is live infrastructure — the Jarvis `transcribe` tool shells out to the installed copy (`--serve`, via a 24/7 LaunchAgent).** A change to its flags, output shape, or the pipeline behind it must keep that contract; `scripts/install-serve.sh` rebuilds and refreshes the installed binary (the LaunchAgent runs from the stable app-owned path, never `.build/`), so re-run it after any CLI change and verify end-to-end.
- **`ShareKit` stays Foundation-only, forever** — the share extensions are memory-capped (~120 MB) and must never gain WhisperKit/SpeakerKit/CoreAI, directly or transitively.
- FCTFoundation is a sibling checkout at `../FCTFoundation`, granular products only.
